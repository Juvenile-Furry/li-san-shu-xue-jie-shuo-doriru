第1回以降で使う記号の最小セット。

この章の内容

  • 直積 A×B

集合と ∈（所属）

a ∈ A …「a は A の元である」／ {a, b, c} … 外延的記法

集合は元の集まりで、順序と重複は無視する。中身を全て並べる書き方が外延的記法、元が無い集合が空集合 ∅、元の個数が |A|。

  • {a, b} = {b, a} = {a, a, b}（順序・重複は関係ない）。
  • a ∉ A は「a は A の元でない」。

例：A = {1, 2, 3} なら 2 ∈ A、5 ∉ A、|A| = 3。

注意　{1, 2} ∈ {1, 2, 3} は誤り。入っているのは数 1, 2, 3 で、集合 {1,2} ではない。

部分集合 ⊆ と べき集合 2^A

B ⊆ A …「B の元はすべて A の元」／ 2^A …「A の部分集合全体の集合」

⊆ は B = A の場合を含む。部分集合は全部で 2|A| 個ある。

  • ∅ と A 自身も必ず部分集合に数える。
  • 各元を「入れる／入れない」の2択で数えると 2|A| 個になる。

例：A = {a, b} なら 2A = {∅, {a}, {b}, {a, b}}（4個）。

注意　∅ を数え忘れるのが定番のミス。

直積 A×B

A × B = { (a, b) | a ∈ A, b ∈ B }

(a, b) は順序対で順番が大事（a ≠ b なら (a,b) ≠ (b,a)）。|A×B| = |A| × |B|。

例：{a, b} × {1, 2, 3} = {(a,1), (a,2), (a,3), (b,1), (b,2), (b,3)}（6個）。

注意　第1回の「関係」は、この直積の部分集合として定義される。

関数とは

f : A → B …「A の各元に、B の元がちょうど1つ対応する」

条件は2つ：(i) A のどの元にも行き先がある、(ii) 行き先は1つだけ。

  • 行き先が重なる（f(a) = f(b)）のは可。
  • 「行き先なし」と「行き先が2つ以上」はどちらも不可。
注意　「出力が1つ」ではなく「入力1つに対して出力が1つ」。

∀ と ∃ の読み方

∀x P(x) …「すべての x について P(x)」／ ∃x P(x) …「P(x) を満たす x が存在する」

例：「∀a ∈ A, aRa」は「A のどの元 a でも aRa」。

関係とは「ペアの集まり」である

ゴール：R⁻¹・Dom／Range を求め、関数になる条件を判定できる。

この回の内容
  • 関係の定義と aRb
  • 逆関係 R⁻¹ と R(a)
  • 空関係・全関係・恒等関係
  • Dom と Range
  • 関係が関数になる条件
  • 例題：演習16.1・16.2

関係の定義 — ペアの集まり

R ⊆ A × B …「R は A から B への（二項）関係」／ (a, b) ∈ R ⇔ aRb

関係とは直積の部分集合のこと。A = B のとき「A 上の関係」という。

逆関係 R⁻¹ と R(a)

R⁻¹ = { (b, a) | (a, b) ∈ R } ／ R(a) = { b | aRb }

R⁻¹ は各ペアの前後を入れ替えた関係で、(R⁻¹)⁻¹ = R。R(a) は a から届く相手の集合（a の像）。

例：R = {(a,a), (a,b), (b,c)} なら R⁻¹ = {(a,a), (b,a), (c,b)}、R(a) = {a, b}、R(c) = ∅。

注意　べき集合上の関係 ⊆ の逆関係は ⊇ になる。

3つの特別な関係

空関係 ∅ ／ 全関係 A×A ／ 恒等関係 idA = { (a, a) | a ∈ A }

id は第2回の R⁰ = id や閉包で繰り返し使う。

Dom と Range

Dom(R) = { a | ∃b, aRb }、Range(R) = { b | ∃a, aRb }

Dom は矢印が出ている元の全体（定義域）、Range は矢印が着く元の全体（値域）。

例：R = {(a,a), (a,b), (b,c)} なら Dom(R) = {a, b}、Range(R) = {a, b, c}。

注意　逆関係では入れ替わる：Dom(R⁻¹) = Range(R)。

関係が関数になる条件

R が関数 ⇔ ∀a ∈ A に対して、aRb となる b がちょうど1つ存在する

判定は2点：(i) Dom(R) = A か、(ii) 1つの a から2本以上出ていないか。

注意　行き先の重なり（f(a) = f(b)）は違反ではない。
例題：演習16.1・16.2開いて読む ▾
演習16.1　A = {a, b, c}。2A の中で、(1) a を含む集合全体、(2) a を含まない集合全体を求めよ。

考え方：2A の8元を「a を含むか」で仕分けるだけ。各グループは 2² = 4 個。

解答　(1) {{a}, {a,b}, {a,c}, {a,b,c}}　(2) {∅, {b}, {c}, {b,c}}

演習16.2　y = x²、y = |x|、y = 2x+3、y = log x の逆関係は関数になるか？

考え方：逆関係が関数でない ⇔ 同じ y に対して x が2つ以上ある。

解答　x²：y=4 で x=±2 → 関数でない。|x|：y=1 で x=±1 → 関数でない。2x+3：x=(y−3)/2 と一意 → 関数。log x：逆は ey → 関数。

合成と閉包

ゴール：S∘R、Rⁿ、R⁺、R* を計算できる。

この回の内容
  • 合成 S∘R
  • 結合法と逆関係の公式
  • 冪 Rⁿ
  • R⁺ と R*
  • 計算例

合成 S∘R

S ∘ R = { (a, c) | ∃b, aRb かつ bSc }

先に R、次に S の順にたどる。「真ん中の元 b が存在する」ことが条件。

注意　S∘R なのに先に R（∘ の右側からたどる）。向きを逆にすると答えが変わる。

結合法と、逆関係の公式

T ∘ (S ∘ R) = (T ∘ S) ∘ R … 結合法則

(S ∘ R)⁻¹ = R⁻¹ ∘ S⁻¹ … 逆関係では順序も逆になる

  • 和集合 R∪S、共通部分 R∩S もペアの集合演算として定義される。

冪 Rⁿ

R¹ = R、R² = R∘R、R³ = R∘R∘R、…、R⁰ = id

(a,c) ∈ Rⁿ ⇔ R をちょうど n 回たどる長さ n のパスが a から c へ存在する（定理3.2）。

推移閉包 R⁺ ／ 反射推移閉包 R*

R⁺ = R ∪ R² ∪ R³ ∪ … ／ R* = R⁺ ∪ id = R⁰ ∪ R¹ ∪ R² ∪ …

R⁺ は1回以上で届く範囲、R* は0回（自分自身）も含む範囲。

注意　R⁺ と R* の差は (a,a) を入れるかどうかだけ。

計算例

A = {a, b, c}、R = {(a,b), (a,c), (b,c)} とする。
  1. R²：2段の道 a→b→c のみ → R² = {(a,c)}。
  2. R³：3段の道なし → R³ = ∅（以降も ∅）。
  3. R⁺ = R ∪ R² = {(a,b), (a,c), (b,c)}、R* = R⁺ ∪ id = {(a,b), (a,c), (b,c), (a,a), (b,b), (c,c)}。

同値関係 ＝ グループ分けのルール

ゴール：3条件を判定し、[a] と A/R を書き出せる。

この回の内容
  • 反射・対称・推移
  • 同値類 [a]
  • 定理3.4と分割・商集合
  • mod m 合同
  • 例題：演習18.1〜18.3

反射・対称・推移

反射的：∀a, aRa ／ 対称的：aRb ⇒ bRa ／ 推移的：aRb かつ bRc ⇒ aRc

同値関係 ＝ 反射的 ＋ 対称的 ＋ 推移的

  • 1つでも欠ければ同値関係ではない（反例1つで判定終了）。
  • 対称でない例：フォロー関係。推移でない例：「友達である」。

同値類 [a]

[a] = { b | aRb } ＝ R(a)

a と関係する元全体、つまり a の属するグループ。a はその代表元で、同じグループなら [a] = [b]。

定理3.4・分割・商集合

定理3.4：[a] = [b] か [a] ∩ [b] = ∅ のどちらかで、同値類の和集合は A 全体

A/R = { [a] | a ∈ A } … 商集合

同値類による重ならない分け方が分割で、「同値関係」と「分割」は1対1に対応する。A/R はグループそのものを集めた集合。

注意　A/R の元の個数は「グループの数」であって、A の元の個数ではない。

mod m 合同

a ≡ b (mod m) ⇔ m | (a − b) ⇔ a と b を m で割った余りが等しい

≡m は同値関係。類を剰余類という。

例（m=3）：[0] = {…, −3, 0, 3, 6, …}、[1] = {…, −2, 1, 4, 7, …}、[2] = {…, −1, 2, 5, 8, …}。[7] = [1]。

例題：演習18.1〜18.3開いて読む ▾
演習18 の型：関係が同値関係か判定し、同値類と商集合を求める。

考え方：反射→対称→推移の順に反例を探し、同値類は未処理の最小元から書き出す。

解答の型　Z/≡₃ = { [0], [1], [2] }。商集合の元は数ではなくグループ（集合）なので、外側にもう一段 { } が付く。

第4回 ・ 同値関係 2/2 ＋ 半順序

細分と半順序

ゴール：剰余類・細分・半順序／全順序を説明できる。

この回の内容
  • 剰余類 Z/≡_m
  • N×N で負の数を「作る」
  • 細分
  • 半順序と全順序
  • 例題：演習19.2

剰余類 Z/≡m

Z/≡m = { [0], [1], …, [m−1] }（ちょうど m 個の類）

整数全体を m で割った余りで分けると、類は m 個で尽きる。

N×N の同値関係 — 負の数の構成

(a, b) ∼ (c, d) ⇔ a + d = b + c

(a, b) を「a − b のつもり」と読む同値関係で、同値類が整数そのものになる（例：[(1,3)] が −2）。商集合 (N×N)/∼ が Z の構成になる。

例：(1,3) ∼ (4,6) ⇔ 1+6 = 3+4 = 7 → 同じ類（−2）。(2,5) は 2+6 ≠ 3+4 → 別の類。

細分

分割 P が分割 Q の細分 ⇔ P の各ブロックが Q のあるブロックに含まれる

≡mn = ≡m ∩ ≡n

関係が小さい（ペアが少ない）ほど類は細かい。

例：≡₆ は ≡₂ の細分（6で割って余りが同じなら、2で割っても同じ）。

半順序と全順序

半順序 ＝ 反射的 ＋ 反対称的 ＋ 推移的（反対称的：aRb かつ bRa ⇒ a = b）

全順序 ＝ 半順序 ＋ 任意の a, b が比較可能

半順序は ≤ で書き、(A, ≤) を半順序集合という。a ≤ b も b ≤ a も成り立たないとき a, b は比較不可能。

例：包含 ⊆ は半順序だが、{a} と {b} が比較不可能なので全順序ではない。数の ≤ は全順序。

注意　「半」は「部分的（partial）」の意味。反対称は「対称でない」とは別物。
例題：演習19.2開いて読む ▾
演習19.2　2A 上の ⊆ は半順序か？ 全順序になるのはどんな A か？

考え方：反射・反対称・推移は集合の性質から直ちに従う。全順序性は比較不可能なペアが作れるかで決まる。

解答　⊆ は常に半順序。全順序になるのは |A| ≤ 1 のときのみ（|A| ≥ 2 では {a} と {b} が比較不可能）。

第5回 ・ 順序 1/2

擬順序、辞書式順序、極大元と最大元

ゴール：< と ≤ を変換でき、極大元と最大元を区別できる。

この回の内容
  • 擬順序
  • < と ≤ の変換、双対
  • 辞書式順序
  • 極大元 vs 最大元
  • 例題：演習20.1・20.2

擬順序

擬順序 ＝ 非反射的（∀a, ¬(a < a)）＋ 推移的

代表例は数の < と真包含 ⊂。非反射＋推移から「a<b かつ b<a は起こらない」が従う。

注意　じゃんけんの「勝つ」は推移的でない（循環する）ので、擬順序でも半順序でもない。

< と ≤ の変換 ／ 双対

a < b ⇔ a ≤ b かつ a ≠ b ／ a ≤ b ⇔ a < b または a = b

双対順序：a ≤op b ⇔ b ≤ a

≤ から「＝」を除くと <、< に「＝」を足すと ≤ になる。≤ の双対は ≥ で、最大⇔最小・sup⇔inf も双対のペア。

辞書式順序

辞書式順序：最初に異なる位置の文字で決める。片方が接頭辞なら短い方が小さい。

例：abc ≺ abcd（接頭辞なので短い方）≺ abd（3文字目 c ≺ d）≺ ad（2文字目 b ≺ d）。

注意　最初に違いが出た位置で決着し、それより後ろは見ない。

極大元／極小元 vs 最大元／最小元

極大元：m より真に大きい元が存在しない ／ 最大元：すべての元 a について a ≤ M

最大元があれば、それは唯一の極大元。極大元が複数あれば最大元は存在しない。最小元・極小元は双対。

例題：演習20.1・20.2開いて読む ▾
演習20.1　文字列を辞書式順序で並べ替える。

考え方：1文字目から順に、最初に違う文字で決める。接頭辞なら短い方が先。例：abc ≺ abcd ≺ abd ≺ ad。

演習20.2　A = {3, 5, 6, 7, 12, 15}、約数順序（a ≤ b ⇔ a | b）の極小元・最小元・極大元・最大元は？

考え方：ハッセ図で「上に出る線がない元」が極大元、「下に出る線がない元」が極小元。

解答　極小元：3, 5, 7／最小元：なし。極大元：7, 12, 15／最大元：なし（極元が複数あるため）。

上界・sup、束、閉包とソート

ゴール：sup／inf・∨／∧ を計算でき、閉包 r／s／t／rst を説明できる。

この回の内容
  • 上界・下界と sup／inf
  • 束と ∨／∧
  • 閉包 r／s／t／rst
  • トポロジカルソート
  • 例題：演習21.1〜21.3

上界・下界、sup・inf

u が B の上界 ⇔ ∀b ∈ B, b ≤ u ／ sup B ＝ 上界の中で最小のもの ／ inf B ＝ 下界の中で最大のもの

sup B が B に属せば B の最大元と一致するが、属さないこともある。

例：B = (0, 1) では上界は 1 以上の数全体で、sup B = 1。ただし 1 ∉ B なので B に最大元はない。同様に inf B = 0。

注意　「最大元はないのに sup はある」が、最大元と sup の決定的な違い。

束と ∨／∧

束：任意の2元 a, b について sup{a,b} と inf{a,b} が存在する半順序集合

a ∨ b = sup{a, b}（結び）、a ∧ b = inf{a, b}（交わり）／ (ℕ, |) では a ∨ b = lcm、a ∧ b = gcd

例：60 = 2²×3×5、55 = 5×11 → 60 ∧ 55 = 5（共通部分）、60 ∨ 55 = 2²×3×5×11 = 660。

閉包 r／s／t／rst

r(R) = R ∪ id ／ s(R) = R ∪ R⁻¹ ／ t(R) = R⁺ ／ rt(R) = R* ／ rst(R) ＝ R を含む最小の同値関係

閉包とは、性質を満たすようペアを最小限だけ付け足す操作。

注意　最小性が定義の半分。足しすぎは不可で、s と t は単純には入れ替えられない。

トポロジカルソート

トポロジカルソート：a < b なら a が b より前に来るような全元の列挙

手順：極小元を1つ選んで取り除くことを繰り返す。選び方が複数あれば答えも複数ある。

例：{3, 5, 6, 7, 12, 15} の約数順序では 3, 5, 6, 7, 12, 15 など（割り切る側が先）。

例題：演習21.1〜21.3開いて読む ▾
演習21.1（上界・sup／inf）

考え方：上界を全部挙げ、その最小が sup。下側は双対に inf。最後に sup が B に属すか確認する。

演習21.2（束の演算）

考え方：約数順序なら ∨＝lcm、∧＝gcd、包含順序なら ∨＝和集合、∧＝共通部分に翻訳して計算する。

演習21.3（閉包）

考え方：公式どおり、r は id、s は逆向き、t は乗り継ぎのペアを追加する。rst は対称化→推移化の順に進め、最後に反射を確認する。

用語・記号辞典

各項目1行。検索で絞り込みできます。

∈所属

a ∈ A：a は A の元。

⊆部分集合

B ⊆ A：B の元はすべて A の元（等しい場合を含む）。

2^Aべき集合

A の部分集合全体。個数は 2^|A|。

∅空集合

元が1つもない集合。ペアのない関係（空関係）にも使う。

A×B直積

順序対 (a,b) 全体。|A×B| = |A|·|B|。

∀ / ∃全称・存在

∀「すべての」、∃「存在する」。

aRb関係の表記

(a,b) ∈ R と同じ意味。

R⁻¹逆関係

全ペアの前後を入れ替えた関係。

R(a)像

{ b | aRb }。同値関係では [a] と一致。

id恒等関係

{ (a,a) | a∈A }。R⁰ でもある。

Dom / Range定義域・値域

Dom＝矢印が出る元全体、Range＝矢印が着く元全体。

S∘R合成

先に R、次に S。(S∘R)⁻¹ = R⁻¹∘S⁻¹。

Rⁿ冪

R の n 回合成＝長さ n のパスで結ばれるペア全体。

R⁺推移閉包 t(R)

R ∪ R² ∪ …（1回以上で届く範囲）。

R*反射推移閉包 rt(R)

R⁺ ∪ id（0回も含む範囲）。

反射的・対称的・推移的

∀a aRa／aRb⇒bRa／aRb∧bRc⇒aRc。

同値関係

反射＋対称＋推移。グループ分けを与える関係。

[a]同値類

a と関係する元全体。[a]=[b] か交わらない（定理3.4）。

分割

全体を重ならず漏れなく分けたブロックの集まり。同値関係と対応。

A/R商集合

同値類全体の集合。

≡ (mod m)合同

m で割った余りが等しい、という同値関係。

剰余類

Z/≡_m の類 [0]…[m−1]。ちょうど m 個。

細分

各ブロックがより粗い分割のブロックに含まれる分け方。例：≡₆ は ≡₂ の細分。

半順序

反射＋反対称＋推移。比較不可能なペアがあってよい。

反対称的

aRb かつ bRa ⇒ a=b。

全順序

どの2元も比較可能な半順序。

擬順序

非反射＋推移（< 型）。≤ とは「＝」の分だけで行き来できる。

双対

順序の上下反転。≤ の双対は ≥、sup⇔inf も双対。

辞書式順序

最初に異なる文字で決める全順序。接頭辞なら短い方が小さい。

極大元・極小元

自分より上（下）がない元。複数ありうる。

最大元・最小元

全員より上（下）の元。あれば1つだけ。

ハッセ図

直上の関係だけを線で結んだ半順序の図。

上界・下界

上界＝部分集合の全元以上の元、下界＝全元以下の元。

sup上限

上界の中で最小のもの。集合に含まれるとは限らない。

inf下限

下界の中で最大のもの。

束（そく）

任意の2元に sup と inf が存在する半順序集合。

∨ / ∧結び・交わり

a∨b = sup{a,b}、a∧b = inf{a,b}。約数順序では lcm／gcd。

r / s / t閉包

r(R)=R∪id、s(R)=R∪R⁻¹、t(R)=R⁺。rst(R) は最小の同値閉包。

トポロジカルソート

半順序の制約を守る全元の一列化。極小元を繰り返し取り除く。

集合と ∈

直積 A × B

写像（関数）

∀ と ∃
