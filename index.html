第0章 ・ 超入門

まず「言葉」から：集合・直積・関数

第1回以降はすべてこの章の言葉で書かれています。ここだけ先に読めば、講義の記号に怖さはなくなります。

この章の内容
  • 集合と ∈（所属）
  • 部分集合 ⊆ と べき集合 2^A
  • 直積 A×B ＝ ペアの全リスト
  • 関数とは
  • ∀ と ∃ の読み方

集合とは — 「ものの集まり」に名前を付ける

① 例え
集合は「袋」だと思ってください。中に何が入っているかだけが大事で、入っている順番や、同じものを2回書くことは意味を持ちません。{a, b} と {b, a} と {a, a, b} はすべて同じ袋です。

② 定義

{a, b, c} … 外延的記法

中身をすべて書き並べて表す書き方を外延的記法といいます（「外に延べる＝全部並べる」）。逆に「偶数全体」のように性質で指定する書き方もあります。

a ∈ A …「a は A の元（要素）である」

∈ は「∈（ぞくする）」と読み、「〜に入っている」という意味。a ∉ A は「入っていない」。袋の中の1つ1つのものを元（げん）／要素と呼びます。何も入っていない袋が空集合 ∅（くうしゅうごう）です。

③ 具体例　A = {1, 2, 3} なら、2 ∈ A（2は入っている）、5 ∉ A（5は入っていない）。A の元の個数を |A| と書き、この場合は |A| = 3 です。

④ よくある誤解「{1, 2} ∈ {1, 2, 3}」は間違いです。{1,2,3} の中に入っているのは 1, 2, 3 という「数」であって、{1,2} という「袋」ではありません。袋が袋の中に入る話は次の ⊆ で出てきます。

部分集合 ⊆ と べき集合 2^A

① 例え
部分集合は「小さい袋が、大きい袋の中身だけで作られている」状態。コンビニの棚（全体）の中から買う物だけを抜き出した買い物かご、が部分集合のイメージです。

B ⊆ A …「B は A の部分集合である」

⊆ は「部分集合（ぶぶんしゅうごう）」の記号。意味は「B の元はすべて A の元でもある」。B = A の場合も含みます（含めたくないときは ⊂ や ⊊ を使う流儀もあります）。

2^A …「A のべき集合」＝ A の部分集合を全部集めた集合

2^A は「2のA乗」と読みます。A の部分集合は全部で 2|A| 個あるので、この名前が付いています。

③ 一歩ずつ　A = {a, b} のべき集合を作ります。各元について「入れる／入れない」の2択があるので 2² = 4 個：
  1. 両方入れない → ∅
  2. a だけ → {a}、b だけ → {b}
  3. 両方入れる → {a, b}
よって 2{a,b} = { ∅, {a}, {b}, {a,b} }。なお∅ と A 自身も必ず部分集合に数えます（ここを忘れるのが定番のミス）。

直積 A×B — 「ペアの全リスト」

① 例え
シャツ {赤, 青} とズボン {黒, 白} のコーディネートは (赤,黒), (赤,白), (青,黒), (青,白) の4通り。この「組み合わせを全部ペアで書き出したもの」が直積です。

A × B = { (a, b) | a ∈ A, b ∈ B }

× は直積（ちょくせき）の記号。(a, b) は順序対（じゅんじょつい）といい、集合と違って順番が大事です：(a, b) ≠ (b, a)（ただし a ≠ b のとき）。|A×B| = |A| × |B|。

③ 具体例　{a, b} × {1, 2, 3} = {(a,1), (a,2), (a,3), (b,1), (b,2), (b,3)} の6個。第1回で学ぶ「関係」は、まさにこの直積の中からペアをいくつか選んだものになります。

関数とは — 「入力1つに、出力がちょうど1つ」

① 例え
関数は自動販売機です。ボタン（入力）を1つ押すと、必ず決まった商品（出力）がちょうど1つ出てきます。「押しても何も出ない」「1つのボタンで2つ出てくる」自販機は壊れていて、関数とは呼びません。

f : A → B

「f は A から B への関数」と読みます。条件は2つ：(i) A のどの元にも行き先がある、(ii) 行き先は1つだけ。行き先が重なる（2つの入力が同じ出力）のはOKです。y = f(x) の x を独立変数、y を従属変数ともいいます。

④ よくある誤解「出力が1つ」ではなく「入力1つに対して出力が1つ」です。また第1回では「関係が関数になる条件」として同じ話が再登場します。

∀ と ∃ — 論理の記号の読み方

∀x P(x) …「すべての x について P(x)」

∀ は All の A をひっくり返した形で「任意の／すべての」と読みます。

∃x P(x) …「P(x) を満たす x が存在する」

∃ は Exist の E の鏡文字で「存在する／ある〜があって」と読みます。

③ 具体例　「∀a ∈ A, aRa」は「A のどの元 a についても aRa が成り立つ」。定義文でこの2記号が読めれば、講義の定義はほぼすべて「日本語の文」として読めます。

⑤ つながり　次の第1回では、集合 A 上の「関係」を A×A の部分集合として定義します。つまりここまでの言葉（集合・部分集合・直積）がそっくりそのまま定義になります。

第1回 ・ 2項関係 1/2

関係とは「つながりのリスト」である

この回のゴール：関係を「ペアの集まり」として読み書きでき、逆関係・Dom／Range が求められ、「いつ関数になるか」を判定できること。

この回の内容
  • 関係の定義と aRb
  • 逆関係 R⁻¹ と R(a)
  • 空関係・全関係・恒等関係
  • Dom と Range
  • 関係が関数になる条件
  • 例題：演習16.1・16.2 の解き方

関係の定義 — ペアの集まり

① 例え
SNSの「フォロー」を思い浮かべてください。「太郎が花子をフォローしている」「花子が次郎をフォローしている」…というつながりの記録を全部集めたリスト、それが関係です。誰と誰がつながっているか、だけが情報です。

R ⊆ A × B …「R は A から B への（二項）関係」

関係（かんけい）とは直積 A×B の部分集合、つまりペアの集まりのこと。A = B のとき「A 上の関係」といいます。3つの集合にまたがるものは3項関係、一般にn項関係です。

(a, b) ∈ R ⇔ aRb

ペア (a,b) が R に含まれるとき、aRb とも書きます（読み方：「a アール b」／「a は b と関係 R にある」）。2つの書き方は同じ意味で、場面で使い分けます。

逆関係 R⁻¹ — 矢印を全部逆向きにする

① 例え
「フォローしている」の逆は「フォローされている」。すべてのつながりの向きをひっくり返したリストが逆関係です。

R⁻¹ = { (b, a) | (a, b) ∈ R }

R⁻¹ は「R の逆関係（ぎゃくかんけい）」と読みます。各ペアの前後を入れ替えるだけです。当然 (R⁻¹)⁻¹ = R（2回ひっくり返せば元通り）。

R(a) = { b | aRb }

R(a) は「a から矢印が届く相手の集まり」。a の像（ぞう）ともいいます。

③ 一歩ずつ　講義の例：A = {a, b, c} 上の R = {(a,a), (a,b), (b,c)}。
  1. 各ペアを入れ替える：(a,a)→(a,a)、(a,b)→(b,a)、(b,c)→(c,b)。
  2. よって R⁻¹ = {(a,a), (b,a), (c,b)}。
  3. R(a) = {a, b}（a から出る矢印の先）、R(b) = {c}、R(c) = ∅（c からは何も出ない）。
③ もう一つの講義例　べき集合 2{a,b,c} 上の関係 ⊆（部分集合である、という関係）も立派な関係です。たとえば {a} ⊆ {a,b} だから ({a}, {a,b}) がこの関係に含まれます。この関係の逆関係は ⊇（含む）になります——「小さい側から大きい側へ」の矢印を逆にすると「大きい側から小さい側へ」になるからです。

3つの特別な関係

空関係 ∅ ／ 全関係 A×A ／ 恒等関係 idA = { (a, a) | a ∈ A }

ペアが1つもない関係が空関係、ありうるペアが全部ある関係が全関係、自分自身へのペアだけを集めたものが恒等関係（こうとうかんけい）id です。id は第2回の「R⁰ = id」や閉包の話で何度も登場する重要人物です。

Dom と Range — 出発点と到着点の集まり

① 例え
矢印図で、矢印が出ている駅の全体が Dom、矢印が着いている駅の全体が Range です。

Dom(R) = { a | ∃b, aRb }、Range(R) = { b | ∃a, aRb }

Dom(R) は「定義域（ていぎいき）」、Range(R) は「値域（ちいき）」と読みます。∃（存在する）が効いていて、「相方が1つでもいれば入る」という意味です。

③ 具体例　R = {(a,a), (a,b), (b,c)}（A={a,b,c}）なら、Dom(R) = {a, b}（c からは矢印が出ていない）、Range(R) = {a, b, c}。なお Dom(R⁻¹) = Range(R) のように、逆関係ではこの2つが入れ替わります。

関係が関数になる条件

① 例え
第0章の自販機の話を矢印図で言い直すと：「すべての出発点から矢印が出ていて、しかも各出発点からの矢印はちょうど1本」。これを満たす関係が関数です。

R が関数 ⇔ ∀a ∈ A に対して、aRb となる b がちょうど1つ存在する

チェックは2段階：(i) Dom(R) = A か（矢印のない元はないか）、(ii) 1つの a から2本以上矢印が出ていないか。どちらかが崩れれば関数ではありません。

④ よくある誤解「行き先が重なる」のは違反ではありません。f(a)=f(b)=c のような「2人から同じ相手へ」はOK。ダメなのは「1人から2人へ」と「誰にも行かない人がいる」場合です。
例題で確認：演習16.1・16.2 の解き方開いて読む ▾
演習16.1　A = {a, b, c} とする。べき集合 2A の中で、(1) a を含む集合すべての集まり、(2) a を含まない集合すべての集まり、を求めよ。

考え方：まず 2A の元は8個：∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}。あとは「a が入っているか」で仕分けるだけです。各元 {b},{c} の運命は a とは無関係に自由なので、各グループは 2² = 4 個ずつになります。

解答

(1) {{a}, {a,b}, {a,c}, {a,b,c}}
(2) {∅, {b}, {c}, {b,c}}

ポイント：2A の元は「集合の集合」なので、外側の { } の中に {a} のような集合が並びます。{a} と a を混同しないこと。

演習16.2　実数上の関係 y = x²、y = |x|、y = 2x+3、y = log x について、それぞれ逆関係は関数になるか？

考え方：逆関係が関数かどうかは、「逆向きにしたとき、入力1つに出力が2つ以上ぶら下がらないか」を見る問題。元の関係で言い換えると「同じ y に対して x が2つ以上あるか」と同じことです。

解答

  • y = x²：y = 4 に対して x = 2 と x = −2 の2つがある → 逆関係で 4 の行き先が2つ → 関数でない。
  • y = |x|：y = 1 に対して x = 1 と −1 → 同じ理由で関数でない。
  • y = 2x+3：x = (y−3)/2 と一意に解ける → 逆関係も関数である。
  • y = log x：逆関係は x = ey（指数関数）→ 関数である。

合言葉：「逆が関数でない ＝ 1つの入力（y）に相手（x）が2つ」。グラフでいえば、横向きの直線が2点で交わるかどうか（水平線テスト）でも判定できます。

⑤ つながり　次回は関係を2つつなぐ「合成」を学びます。逆関係 R⁻¹ は合成の公式 (S∘R)⁻¹ = R⁻¹∘S⁻¹ で再登場します。

第2回 ・ 2項関係 2/2

合成は「乗り継ぎ」、閉包は「届く範囲すべて」

ゴール：合成 S∘R を「真ん中の元探し」で計算でき、冪 Rⁿ、推移閉包 R⁺、反射推移閉包 R* を具体的に求められること。

この回の内容
  • 合成 S∘R
  • 結合法と逆関係の公式
  • 冪 Rⁿ と R⁰ = id
  • R⁺ と R*（閉包）
  • 講義例を全部計算する

合成 S∘R — 電車の乗り継ぎ

① 例え
「東京 →（JRで）→ 横浜 →（私鉄で）→ 鎌倉」。2つの路線をつないで1本の旅程にするのが合成です。ポイントは乗り換え駅（真ん中の元）が存在すること。

S ∘ R = { (a, c) | ∃b, aRb かつ bSc }

S∘R は「S 合成 R」と読み、先に R、次に S の順にたどります（関数の合成 f(g(x)) と同じ向きの約束）。「∃b」が心臓部で、「真ん中の b が（1つでも）存在すれば (a,c) を入れる」という定義です。

④ 最大のひっかけ：合成の向きS∘R なのに「先に R」。なぜこの順かというと、関数の書き方 f(g(x))（先に g を適用）を関係に引き継いだためです。「∘ の右側からたどる」と覚えてください。順序を逆にすると答えが変わります。

結合法と、逆関係の公式

T ∘ (S ∘ R) = (T ∘ S) ∘ R … 結合法則

(S ∘ R)⁻¹ = R⁻¹ ∘ S⁻¹ … 逆関係では順序もひっくり返る

2つ目の公式は「靴下を履いて靴を履いたら、脱ぐときは逆順」というあの原則です。旅程全体を逆向きにたどるには、各区間を逆向きにし、かつ区間の順序も逆にしなければなりません。

また関係どうしの和集合 R∪S（どちらかの矢印があれば引く）や共通部分 R∩S（両方の矢印があるときだけ引く）も、ペアの集まりとして普通の集合演算で定義されます。

冪 Rⁿ — n回乗り継ぎ

R¹ = R、R² = R∘R、R³ = R∘R∘R、…、R⁰ = id

Rⁿ は「R の n 乗／n回合成」。R² のペア (a,c) は「R をちょうど2回乗り継いで a から c へ行ける」という意味です。R⁰ は「0回移動＝その場にいる」なので恒等関係 id になります。

推移閉包 R⁺ ／ 反射推移閉包 R*

① 例え
乗り継ぎ回数を「何回でもよい」にしたとき、a から届く駅のすべて——それが閉包の発想です。「友達の友達の友達…」とたどれる人全員、と思ってもらっても構いません。

R⁺ = R ∪ R² ∪ R³ ∪ … （1回以上の乗り継ぎで届く範囲）

R* = R⁺ ∪ id = R⁰ ∪ R¹ ∪ R² ∪ … （自分自身も含める）

R⁺ は推移閉包（すいいへいほう）、R* は反射推移閉包（はんしゃすいいへいほう）と読みます。R* は「0回移動」も許すぶん、必ず (a,a) を含みます。

定理3.2：(a, b) ∈ Rⁿ ⇔ a から b へ長さ n のパス（道）が存在する

つまり Rⁿ の計算は「長さ n の道を全部数える」ことと等しい、という橋渡し定理です。

講義例を、全部計算してみる

③ 一歩ずつ　A = {a, b, c}、R = {(a,b), (a,c), (b,c)}（矢印：a→b、a→c、b→c）として、R²、R³、R⁺、R* を求めます。
  1. R²：「真ん中」を探します。a→b→c が唯一の2段乗り継ぎ（a→c の先には何もない、b→c の先にも何もない）。よって R² = {(a,c)}。
  2. R³ = R²∘R：(a,c) の先 c からは矢印が出ないので、3段の道は存在せず R³ = ∅。以降 R⁴, R⁵, … もすべて ∅ です。
  3. R⁺ = R ∪ R² ∪ R³ ∪ … = {(a,b), (a,c), (b,c)} ∪ {(a,c)} = {(a,b), (a,c), (b,c)}（今回は R と一致）。
  4. R* = R⁺ ∪ id = {(a,b), (a,c), (b,c), (a,a), (b,b), (c,c)}。
行列風にまとめると、どのペアが何回で届くか一目瞭然です（数字＝必要な乗り継ぎ回数、0 は自分自身、× は届かない）：
出発＼到着abc
a0回（R*のみ）1回1回・2回
b×0回（R*のみ）1回
c××0回（R*のみ）
④ よくある誤解R⁺ と R* の違いは「自分自身 (a,a) を入れるかどうか」だけです。また、R² は「R のペアを2回使う」のであって「同じペアを2回」ではありません。真ん中の元は毎回探し直します。

⑤ つながり　R* は第6回で「反射推移閉包 rt(R) = R*」として再登場します。ここで計算に慣れておくと第6回が一気に楽になります。

第3回 ・ 同値関係 1/2

同値関係 ＝「同じグループ分け」のルール

ゴール：反射・対称・推移の3条件を自分の言葉で説明でき、同値類 [a] と商集合 A/R を具体的に書き出せること。

この回の内容
  • 3つの性質：反射・対称・推移
  • 同値類 [a]
  • 定理3.4と分割・商集合
  • mod m 合同
  • 例題：演習18.1〜18.3 の考え方

反射・対称・推移 — グループ分けの3条件

① 例え
「同じクラスである」という関係を考えてください。(i) 自分は自分と同じクラス（当たり前）、(ii) 私があなたと同じクラスなら、あなたも私と同じクラス、(iii) 私とあなた、あなたと彼が同じクラスなら、私と彼も同じクラス。この3つが成り立つ関係は、クラスという「きれいなグループ分け」を生みます。

反射的：∀a, aRa

対称的：∀a,b, aRb ⇒ bRa

推移的：∀a,b,c, aRb かつ bRc ⇒ aRc

同値関係 ＝ 反射的 ＋ 対称的 ＋ 推移的 な関係

1つでも欠けると「グループ分け」としては破綻します。対称でない関係（例：フォロー）はグループにならず、推移でない関係（例：「友達である」は友達の友達が友達とは限らない）もグループになりません。

同値類 [a] — グループの名簿

[a] = { b | aRb } ＝ R(a)

[a] は「a の同値類（どうちるい）」と読み、a と関係のある元すべての集まり、つまりa が所属するグループの名簿そのものです。第1回の R(a) と定義は同じで、「関係が同値関係のときは特別に [a] と書く」と思えばOKです。a をその類の代表元といいますが、代表は誰でもよく、[a] = [b]（a と b が同じグループなら名簿は同一）となります。

定理3.4・分割・商集合

定理3.4：任意の a, b について、[a] = [b] か [a] ∩ [b] = ∅ のどちらか。そして全ての同値類の和集合は A 全体。

つまり同値類は「完全に一致するか、まったく重ならないか」のどちらかで、しかも全体を漏れなく覆います。このような分け方を分割（ぶんかつ）といい、「同値関係」と「分割」は同じものの裏表です。

A/R = { [a] | a ∈ A } … 商集合

A/R は「A 割る R」と読み、グループそのものを元として集めた集合です。「クラス名簿の一覧表」が商集合です。

mod m 合同 — 「余りが同じ」という同値関係

① 例え
時計は mod 12 の世界です。13時と1時は「12で割った余りが同じ」ので同じ位置を指します。「余りでグループ分けする」のが合同の発想です。

a ≡ b (mod m) ⇔ m | (a − b) ⇔ a と b を m で割った余りが等しい

≡ は合同（ごうどう）の記号で「a コングルエント b モッド m」と読みます。≡m と書くこともあります。これは同値関係です（反射：余りは自分と同じ／対称：明らか／推移：余りが同じもの同士は同じ）。

③ 一歩ずつ　m = 3 で整数を仕分けします。余りは 0, 1, 2 の3通りしかないので、グループも3つ：
  • [0] = {…, −3, 0, 3, 6, 9, …}（3の倍数）
  • [1] = {…, −2, 1, 4, 7, 10, …}
  • [2] = {…, −1, 2, 5, 8, 11, …}
確認：7 ∈ [1] なのは 7 = 3×2 + 1 と余り1だから。[7] と書いても [1] と同じ名簿です（7≡1 mod 3）。
例題で確認：演習18.1〜18.3 の考え方開いて読む ▾
演習18 の共通テーマ：与えられた関係が同値関係か判定し、同値類と商集合を求める。

考え方（手順）

  1. 3条件チェック：反射（自分自身とのペアは常にあるか）→ 対称（矢印は常に戻れるか）→ 推移（2段乗り継ぎでショートカットがあるか）。1つ反例を見つければ「同値関係でない」で終了です。反例探しは小さい元から試すのがコツ。
  2. 同値類を書き出す：まだ名簿に入っていない一番小さい元を代表に取り、その元と関係のあるものを全部集めて1グループ。尽きるまで繰り返します（定理3.4のおかげで、重なりを心配しなくてよい）。
  3. 商集合にまとめる：できたグループを { } で包んで並べれば A/R の完成。

解答の型（≡₃ の場合）

Z/≡₃ = { [0], [1], [2] }、各類は上の③で書き出した通り。商集合の元は「数」ではなく「グループ（集合）」である点に注意——だから外側にもう一段 { } が付きます。

④ よくある誤解[a] は「a を含む集合」ではありますが、[a] の中身は a だけではありません。また商集合 A/R の元の個数は、元の集合 A の元の個数ではなく「グループの数」です（≡₃ なら無限の整数がたった3グループ）。

第4回 ・ 同値関係 2/2 ＋ 半順序

細分でグループを割り、半順序で「比べられない」を許す

ゴール：剰余類 Z/≡m の構造と「負の数を作る」同値関係が分かり、細分と半順序／全順序の違いを説明できること。

この回の内容
  • 剰余類 Z/≡_m
  • N×N で負の数を「作る」
  • 細分
  • 半順序と全順序
  • 例題：演習19.2

剰余類 Z/≡m — 余りのグループの正式名

Z/≡m = { [0], [1], …, [m−1] }（m 個の類）

≡m による同値類を剰余類（じょうよるい）と呼びます。「整数全体を m で割った余りで仕分ける」と、無限の整数がちょうど m 個のグループに収まります。第3回の ≡₃ はその m=3 の場合でした。

N×N の同値関係 — 負の数を「作る」話

① 例え
自然数（0,1,2,…）の世界には「−2」がありません。でも「3 − 5」のような引き算の“つもり”をペアで表すことはできます。(a, b) を「a − b のつもり」と読む約束にすると、(1, 3) も (4, 6) も (0, 2) も、すべて「−2 のつもり」です。

(a, b) ∼ (c, d) ⇔ a + d = b + c

この ∼ は N×N 上の同値関係です。条件 a+d = b+c は「a−b = c−d（引き算が同じ）」を、負の数を使わずに言い換えたものです。同値類 [(1,3)] が、数学的には整数 −2 そのものとして扱われます。商集合 (N×N)/∼ が整数の集合 Z の「設計図」になっている、という壮大な話の入口です。

③ 確認　(1,3) ∼ (4,6) か？ a+d = 1+6 = 7、b+c = 3+4 = 7 で等しい → 同じ類（どちらも −2）。(2,5) は？ 2+6=8 ≠ 3+4=7 → 別々の類（−3 の側）。

細分 — グループをより細かく割る

① 例え
「学年で分ける」より「クラスで分ける」ほうが細かい。同じ全体を分ける2つの方法について、片方のグループがもう片方のグループの中にすっぽり収まっているとき、「より細かい」＝細分といいます。

分割 P が分割 Q の細分 ⇔ P の各ブロックが Q のあるブロックに含まれる

同値関係の言葉では「関係が小さい（ペアが少ない）ほど類は細かく」なります。例：≡₆ は ≡₂ の細分。6で割った余りが同じ2数は、2で割った余りも当然同じだからです。([0]₆ ⊆ [0]₂、[1]₆ ⊆ [1]₂、[2]₆ ⊆ [0]₂、…のように6個の類が2個の類に分配されます。)

≡mn = ≡m ∩ ≡n

「mn で割って余りが同じ」は「m でも n でも余りが同じ」と同等、という形で、共通部分 ∩ が「両方の条件を課す＝より細かい関係」に対応します。

半順序 — 比べられないペアがあってよい

① 例え
社内の「上司である」関係や、単位の「前提科目である」関係では、横並びで上下を比べられないペアが普通にあります。それでも「順序っぽい」構造はあります。それを切り取ったのが半順序です。

半順序 ＝ 反射的 ＋ 反対称的 ＋ 推移的

反対称的：aRb かつ bRa ⇒ a = b

反対称は対称の対極：「両向きに矢印があるのは、自分自身への矢印だけ」という条件です。半順序は通常 ≤ の字で書き、(A, ≤) を半順序集合といいます。

全順序 ＝ 半順序 ＋ 任意の a, b が比較可能

a と b について a ≤ b か b ≤ a の少なくとも一方が必ず成り立つ半順序が全順序（数直線の ≤ が代表）。半順序で a ≤ b も b ≤ a も成り立たないとき、a と b は比較不可能といいます。

③ 具体例　集合の包含 ⊆ は半順序です：{a} と {b} はどちらも他方を含まないので比較不可能。だから ⊆ は（大きな集合については）全順序ではありません。一方、普通の数の ≤ は全順序です。

例題で確認：演習19.2 の考え方開いて読む ▾
演習19.2　べき集合 2A 上の包含関係 ⊆ は半順序か？ 全順序になるのはどんな A か？

考え方：(i) 反射：どの集合 X も X ⊆ X。(ii) 反対称：X ⊆ Y かつ Y ⊆ X なら X = Y（集合の相等そのもの）。(iii) 推移：X ⊆ Y、Y ⊆ Z なら X ⊆ Z。よって ⊆ は常に半順序です。全順序かどうかは「比較不可能なペアを作れるか」で決まります。

解答

|A| ≥ 2 なら、A の元 a ≠ b に対して {a} と {b} が比較不可能なので全順序ではない。逆に |A| ≤ 1 のとき全順序になる：|A| = 0 なら 2A = {∅} で1元のみ、|A| = 1 なら 2A = {∅, A} で ∅ ⊆ A と鎖状に並びます。

④ よくある誤解「半」は「半分」という意味ではなく「部分的に（partially）順序が付いている」という意味（英語の partial order の訳）です。また反対称と「対称でない」は別物：反対称は a≠b のペアに両向き矢印が決してないこと、を要求します。

第5回 ・ 順序 1/2

擬順序、辞書式順序、そして「一番」の2つの意味

ゴール：< と ≤ の行き来ができ、辞書式順序で文字列を並べ替えられ、極大元と最大元を図で区別できること。

この回の内容
  • 擬順序（< の世界）
  • < と ≤ の変換、双対
  • 辞書式順序
  • 極大元 vs 最大元
  • 例題：演習20.1・20.2

擬順序 — 「自分とは比べない」版の順序

① 例え
数の <（小なり）は「自分より小さい」だけを比べ、自分自身とは比べません（a < a は偽）。この「自分を除く」流儀を一般化したものが擬順序です。

擬順序 ＝ 非反射的（∀a, ¬(a < a)）＋ 推移的

擬順序（ぎじゅんじょ）の代表例は数の < と、集合の真包含 ⊂ です。なお非反射＋推移からは反対称にあたる性質（a<b かつ b<a は起こらない）が自動的に従います。

④ 反例の味方：じゃんけん「グーはチョキに勝ち、チョキはパーに勝ち、パーはグーに勝つ」——「勝つ」関係は推移的でありません（グーはチョキに勝ち、チョキはパーに勝つのに、グーはパーに勝たない）。だから「勝つ」は擬順序でも半順序でもありません。推移性のチェックには、まず循環する例がないか探すのが近道です。

< と ≤ の変換 ／ 双対

a < b ⇔ a ≤ b かつ a ≠ b　／　a ≤ b ⇔ a < b または a = b

半順序 ≤ から「＝ の分を取り除く」と擬順序 < が得られ、逆に擬順序に「＝ を足す」と半順序が得られます。2つの世界は「等号を含むかどうか」の1点だけで行き来できる、というのがこの回の最初の山です。

双対順序：a ≤op b ⇔ b ≤ a

順序を上下ひっくり返したものが双対（そうつい）。≤ の双対は ≥ です。以後の「最大／最小」「sup／inf」は双対のペアになっていて、片方を理解すればもう片方は上下逆に読むだけです。

辞書式順序 — 辞書の引き方そのもの

① 例え
国語辞典の並び順を思い出してください。まず1文字目で比べ、それが同じときだけ2文字目を見る。文字列の全順序がこの仕組みで作れます。

辞書式順序：最初に異なる位置の文字で勝敗を決める。片方がもう片方の接頭辞（先頭部分）なら、短い方を小さいとする。

③ 一歩ずつ　abc ≺ abcd ≺ abd ≺ ad を確かめます（≺ は辞書式順序の記号）：
  1. abc vs abcd：3文字目まで完全一致し、abc が尽きる。abc は abcd の接頭辞なので短い方 abc が小さい → abc ≺ abcd。
  2. abcd vs abd：1文字目 a＝a、2文字目 b＝b、3文字目で c と d が異なる。c ≺ d なので abcd ≺ abd（4文字目は見ない）。
  3. abd vs ad：2文字目で b と d が異なる。b ≺ d なので abd ≺ ad。
ルールは「最初に違いが出た場所で決着。それより後ろは見ない」です。

極大元／極小元 vs 最大元／最小元

① 例え
山登りで言えば——極大元は「自分の上に誰もいない人」（独立した山の頂上は複数ありうる）。最大元は「全員より上にいる唯一の人」（世界最高峰は1つだけ）。この違いが第5回最大のテーマです。

極大元：m が極大 ⇔ m より真に大きい元が存在しない

最大元：M が最大 ⇔ すべての元 a について a ≤ M

最大元があれば、それは唯一の極大元でもあります。しかし極大元が複数あるとき最大元は存在しません（「全員より上」が誰にも当てはまらない）。最小元・極小元は上下逆の双対の概念です。

例題で確認：演習20.1・20.2 の解き方開いて読む ▾
演習20.1　文字列を辞書式順序で並べ替える問題。

考え方：比較は必ず「1文字目から順に、最初に違う文字で決める」「接頭辞なら短い方が先」。代表例の並びは abc ≺ abcd ≺ abd ≺ ad で、比べ方は③で一歩ずつ追った通りです。迷ったら2語ずつ取り出して同じ手順を繰り返してください。

演習20.2　A = {3, 5, 6, 7, 12, 15} 上の約数順序（a ≤ b ⇔ a は b を割り切る）について、極小元・最小元・極大元・最大元を求めよ。

考え方：ハッセ図を描くのが正攻法です。割り切る関係は 3|6、3|12（6経由でも可）、3|15、5|15（7はどれとも無関係に孤立）。「線が上に出ていない元」が極大元、「線が下に出ていない元」が極小元。最大元は「全元と比較可能で一番上」の元があるかで判定します。

解答

極小元：3, 5, 7／最小元：なし（極小元が複数）
極大元：12, 15／最大元：なし（極大元が複数）

暗記ではなく「極元は複数ありうる／最大・最小はあれば1つだけ」という原則から導けるのがポイントです。

第6回 ・ 順序 2/2

上界・sup、束、そして閉包とソート

ゴール：上界・下界から sup／inf を求められ、束の演算 ∨／∧ を約数順序で計算でき、4つの閉包 r／s／t／rst の役割を説明できること。

この回の内容
  • 上界・下界と sup／inf
  • 束と ∨／∧
  • 閉包 r／s／t／rst
  • トポロジカルソート
  • 例題：演習21.1〜21.3 の手順

上界・下界、sup（上限）・inf（下限）

① 例え
部分集合 B の上界は「B の全員以上の高さにある天井候補」、その中で一番低い天井が sup（上限）です。天井が部屋の中（B の中）にあるとは限らない——これが sup の一番大事な性質です。

u が B の上界 ⇔ ∀b ∈ B, b ≤ u

sup B ＝ B の上界全体の中で最小のもの（上限）

inf B ＝ B の下界全体の中で最大のもの（下限）

sup は「スープ（シュプレマム）」、inf は「インフ（インフィマム）」と読みます。sup B が B に属せばそれは B の最大元と一致しますが、属さないこともあります。

③ 具体例：開区間 (0,1)　実数の通常の順序で B = (0, 1)（0と1を含まない）を考えます。
  • 上界：1 以上の数すべて（1, 1.5, 2, …）。
  • その中で最小は 1 → sup B = 1。
  • しかし 1 ∉ B。だから B に最大元はないのに sup は存在する——これが「最大元」と「sup」の決定的な違いです。同様に inf B = 0 で、これも B に含まれません。

束（そく）と、結び ∨ ／ 交わり ∧

① 例え
どんな2元にも「共通の天井の一番低いもの」と「共通の床の一番高いもの」が必ず用意されている世界——それが束です。

束：任意の2元 a, b について sup{a,b} と inf{a,b} が存在する半順序集合

a ∨ b = sup{a, b} … 結び（ジョイン）、a ∧ b = inf{a, b} … 交わり（ミート）

∨ は「ヴェー／または型」の記号で結び、∧ は交わりと読みます。

(ℕ, |)（約数順序）では：a ∨ b = 最小公倍数 lcm、a ∧ b = 最大公約数 gcd

「a と b の両方を割り切る数の中で一番小さいもの」が最小公倍数＝sup、「両方を割り切る中で一番大きいもの」が最大公約数＝inf だからです。

③ 一歩ずつ：60 ∨ 55 と 60 ∧ 55
  1. 素因数分解：60 = 2² × 3 × 5、55 = 5 × 11。
  2. ∧（gcd）は「共通部分を小さい指数で」：共通する素数は 5 のみ → 60 ∧ 55 = 5。
  3. ∨（lcm）は「全部を大きい指数で」：2² × 3 × 5 × 11 = 4 × 3 × 55 = 660。
検算：660 ÷ 60 = 11、660 ÷ 55 = 12 で、確かに両方の倍数の中で最小です。

閉包 r／s／t／rst — 足りない性質を最小限だけ補う

① 例え
「閉包」とは、希望の性質を持つようになるまで、ペアを最小限だけ付け足す手術です。多く足しすぎてもダメ（元の関係を含む最小のもの、が条件）。

反射閉包 r(R) = R ∪ id

対称閉包 s(R) = R ∪ R⁻¹

推移閉包 t(R) = R⁺

反射推移閉包 rt(R) = R*

rst(R) ＝ R を含む最小の同値関係

各公式は「足りない矢印の正体」をそのまま書いたものです：反射には (a,a) が、対称には逆向きの矢印が、推移には乗り継ぎの結果が足りません。第2回の R⁺・R* がここで閉包として再登場していることに注目してください。rst 閉包は3つの手術の合わせ技で、結果は「R の矢印（とその逆）でたどれる範囲がグループになる」同値関係です。

④ よくある誤解閉包は「性質を満たすまで足す」のであって、「性質を満たすものなら何でもよい」わけではありません。最小性（それ以上削れない）が定義の半分です。また rt(R) = r(t(R)) = t(r(R)) のように順序を入れ替えられる組もありますが、s と t は単純には入れ替えられず、rst は正しい順序で合成する必要があります。

ソートとトポロジカルソート

① 例え
「前提科目を先に履修する」「下着→シャツ→ジャケットの順に着る」のように、半順序の制約を壊さず一列に並べ替えるのがトポロジカルソートです。全順序でない半順序でも、「一列化」なら可能なことが多いのです。

トポロジカルソート：a < b なら a が b より前に来るような全元の列挙

手順：極小元（今のところ前提が残っていない元）を1つ選んで先頭に置き、取り除く。これを繰り返すだけです。選ぶ極小元が複数あれば、そのぶん答えも複数通りあります（どれも正解）。

③ 具体例　第5回の約数順序 A = {3, 5, 6, 7, 12, 15} を並べます。極小元は {3, 5, 7}。たとえば 3 を取り除くと極小元は {5, 6, 7}、次に 5 を取ると {6, 7, 15}、…という具合に進めて、たとえば 3, 5, 6, 7, 12, 15 や 7, 3, 5, 6, 15, 12 などが得られます。どちらも「割り切る側が先」という制約を守っています。
例題で確認：演習21.1〜21.3 の解き方（手順まとめ）開いて読む ▾
演習21.1（上界・sup／inf 型）

手順：(1) 対象の部分集合 B の全員以上にある元をすべて挙げる＝上界の集合。(2) 上界の中で最小のものを探す＝sup。(3) 下側も双対に繰り返す＝inf。(4) sup が B に属すかチェックし、属せば「それが最大元」とも言える。ハッセ図があれば、上界は「B の全元から上にたどって共通して届く点」として目で探せます。

演習21.2（束の演算 型）

手順：約数順序なら a∨b＝lcm、a∧b＝gcd に翻訳してから素因数分解で計算（③の 60 と 55 の型）。包含順序 2A なら a∨b＝和集合、a∧b＝共通部分です。「順序 → 演算への翻訳表」を先に作るのがコツ。

演習21.3（閉包 型）

手順：求める閉包に応じて公式をそのまま適用します。r なら id のペアを全追加、s なら各ペアの逆を追加、t なら乗り継ぎで生まれるペアを（なくなるまで）追加。有限集合なら矢印図に書き足していく方法が確実で、「もう追加できない」状態が答えです。rst が問われたら、まず対称化→推移化の順に進め、最後に反射ペアを確認します。

⑤ 6回の総まとめ　第1回「ペアの集まり」から出発し、合成と閉包（第2回）、同値関係とグループ分け（第3〜4回）、半順序と極元・sup（第4〜6回）まで、すべては「関係にどんな条件を付けるか」の違いでした。この一文が腑に落ちれば、講義6回分の地図は完成です。

用語・記号辞典

講義6回分に出てきた記号と用語の総一覧です。読み返しのときに「あの記号なんだっけ？」をここで解決してください。検索窓で絞り込みもできます。

∈所属

a ∈ A：「a は A の元である」。読み方「ぞくする」。

⊆部分集合

B ⊆ A：B の元はすべて A の元。等しい場合も含む。

2^Aべき集合

A の部分集合全部の集合。元の数は 2^|A| 個。

∅空集合

元が1つもない集合。空関係（ペアなしの関係）にも同じ記号。

A×B直積

順序対 (a,b) 全体の集合。|A×B| = |A|·|B|。

∀ / ∃全称・存在

∀「すべての」、∃「存在する」。定義文を読む鍵。

aRb関係の表記

(a,b) ∈ R と同じ意味。「a は b と関係 R にある」。

R⁻¹逆関係

全ペアの前後を入れ替えた関係。矢印を逆向きにする。

R(a)像

{ b | aRb }、a から矢印が届く相手の集まり。同値関係では [a] と一致。

id恒等関係

{ (a,a) | a∈A }。自分自身へのペアだけの関係。R⁰ でもある。

Dom / Range定義域・値域

Dom＝矢印が出ている元の全体、Range＝矢印が着く元の全体。

S∘R合成

先に R、次に S。「真ん中の元」が存在するペアの集まり。(S∘R)⁻¹ = R⁻¹∘S⁻¹。

Rⁿ冪

R の n 回合成。長さ n のパスで結ばれるペア全体（定理3.2）。

R⁺推移閉包 t(R)

R ∪ R² ∪ …、1回以上の乗り継ぎで届く範囲。

R*反射推移閉包 rt(R)

R⁺ ∪ id、0回移動（自分自身）も含む到達範囲。

反射的・対称的・推移的

∀a aRa／aRb⇒bRa／aRb∧bRc⇒aRc。関係の基本3性質。

同値関係

反射＋対称＋推移。「同じグループ分け」を与える関係。

[a]同値類

a と関係する元の全体＝a のグループ名簿。[a]=[b] か交わらない（定理3.4）。

分割

全体を重ならず漏れなく分けたブロックの集まり。同値関係と対応。

A/R商集合

同値類全体の集合。「グループの一覧表」。

≡ (mod m)合同

m で割った余りが等しい、という同値関係。同値類は剰余類。

剰余類

Z/≡_m の類 [0]…[m−1] のこと。ちょうど m 個ある。

細分

分割の各ブロックがより粗い分割のブロックに含まれるとき、より細かい方を細分という。例：≡₆ は ≡₂ の細分。

半順序

反射＋反対称＋推移。比較不可能なペアがあってよい。

反対称的

aRb かつ bRa ⇒ a=b。両向き矢印は自分自身だけ。

全順序

どの2元も比較可能な半順序。比較不可能＝どちらも成り立たない状態。

擬順序

非反射＋推移の順序（< 型）。≤ とは「＝」の分だけで行き来できる。

双対

順序を上下反転したもの。≤ の双対は ≥。最大⇔最小、sup⇔inf も双対。

辞書式順序

最初に異なる文字で決める文字列の全順序。接頭辞なら短い方が小さい。

極大元・極小元

「自分より上（下）がいない」元。複数ありうる。

最大元・最小元

「全員より上（下）」の元。あれば1つだけ。極元のうち全員と比較可能なもの。

ハッセ図

半順序を、直上の関係だけ線で結んで描く図。上下位置が順序を表す。

上界・下界

上界＝部分集合の全元以上の元、下界＝全元以下の元。

sup上限

上界の中で最小のもの。部分集合に含まれるとは限らない（例：(0,1) の sup=1）。

inf下限

下界の中で最大のもの。sup と双対。

束（そく）

任意の2元に sup と inf が存在する半順序集合。

∨ / ∧結び・交わり

a∨b = sup{a,b}、a∧b = inf{a,b}。約数順序では lcm／gcd。

r / s / t閉包

r(R)=R∪id、s(R)=R∪R⁻¹、t(R)=R⁺。「最小限だけ付け足す」操作。rst(R) は最小の同値閉包。

トポロジカルソート

半順序の制約を守って全元を一列に並べること。極小元を繰り返し取り除く。

はじめの5分：超入門（前提知識の確認）

たとえば
集合は「ものの集まりを入れた袋」、関係は「袋の中のもの同士のつながりを書いたリスト」です。この2つが分かれば第1回から進めます。
集合と外延的記法
中身を全部書き並べて表す書き方です。
A = {a, b, c} は「元（なかみ）が a, b, c の集合」。順番は関係なく、重複は書きません。a ∈ A は「a は A の元である（a が袋に入っている）」という意味です。
部分集合 ⊆
「小さい袋の中身が、全部大きい袋にも入っている」状態です。
A ⊆ B ⟺ A の元はすべて B の元でもある。例：{a, c} ⊆ {a, b, c}。A の部分集合を全部集めた集合を冪集合といい 2A と書きます（A の元が n 個なら部分集合は 2n 個）。
直積 A × B
A の元と B の元で作れる「ペア」の全パターンです。席の組み合わせ表をイメージしてください。
A × B = {(a, b) | a ∈ A, b ∈ B}。ペア (a, b) は順序が大事（(a,b) と (b,a) は別物）。元の個数は |A × B| = |A| · |B|。
写像（関数）
「入力1つに対して出力がちょうど1つ決まる対応」です。自販機のボタン1つに商品1つ、が関数のイメージ。
f : A → B は、A のどの元にも B の元がちょうど1つ対応する決まり。第1回では「関係が関数になる条件」として再登場します。
論理記号 ∀ と ∃
∀ は「すべて」、∃ は「（少なくとも1つ）存在する」の略記です。
∀a ∈ A [ … ] は「A のすべての a について …」、∃b [ … ] は「… を満たす b が存在する」。定義はこの記号で書かれることが多いので、読み方だけ覚えておきましょう。
